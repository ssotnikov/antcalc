# Происхождение эталонов совместимости

`reference-verification.json` — побайтовая копия `.research/reference-verification.json`.
Семь записей получены исполнением расчётных участков исходного ARM-калькулятора
в Unicorn при первоначальном анализе 3 ноября 2026 года. Графические вызовы
перехватывались; целочисленный расчёт исполнялся из исходного машинного кода.
Это проверка расчётных участков, а не запуск полного интерфейса устройства.

SHA-256 исходного бинарного файла (из отчёта анализа):
`d4975dba6128a72dd5187af15d32bc469149bd76c5c797b92d7821ad392132a2`.

SHA-256 копируемого JSON:
`9a12a3c4064b7dbc4d5659f5ce04faf418de6ad7808e7eae2228a21912f20124`.

Файл исследования сохраняется без изменений. Тест проверяет целостность копии
и сравнивает каждый результат с записанными числами и командой; ожидаемые
значения не вычисляются заново проверяемой реализацией.
Исходный бинарный файл не является зависимостью тестов или APK.
Gson используется только в тестах для чтения JSON.
